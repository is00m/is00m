## About

I make games. Most days that means Roblox: writing gameplay in Luau, building menus and
HUDs, and modeling whatever assets I need in Blender. Unity and C# on the side.

Before games I was doing backend work, mostly Java and Spring Boot, and I still pick it up
when a project calls for it. Lately that's been automation: trading bots, and a pipeline
that writes Etsy listings and generates the product images to go with them.

**I'm looking for game development work**, Roblox or Unity, full-time or contract. Backend
and automation projects are welcome too, but games are where I'd rather spend my time.

Most of what I'm working on right now sits in private repos. Ask me and I'll walk you through it.
